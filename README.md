# Financial Simulation

A collection of interactive tools for financial education.

## Web tools

- [Launch the Portfolio Allocation Lab](https://wofuergithub.github.io/Financial-Simulation/interactive_portfolio_simulator.html) — compare historical returns and portfolio allocations.
- [Launch the Protective Put Portfolio Lab](https://wofuergithub.github.io/Financial-Simulation/protective_put_portfolio_simulator.html) — explore a modeled S&P 500 protective-put strategy.
- [View the tool's source](./interactive_portfolio_simulator.html).
- [View the protective put simulator's source](./protective_put_portfolio_simulator.html).

The launch link works after the repository's GitHub Pages site has been enabled and the deployment workflow has completed. To enable it, open **Settings → Pages** and select **GitHub Actions** as the build and deployment source. Future updates to `main` deploy automatically.
